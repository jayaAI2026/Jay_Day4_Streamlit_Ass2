# Student Grade System

A simple Student Grade System created using Python and Streamlit.

## Grade Criteria

- 90 - 100 → A
- 80 - 89 → B
- 70 - 79 → C
- 60 - 69 → D
- 0 - 59 → E
- Below 0 or Above 100 → Invalid

## Features

- Enter student name
- Enter student marks
- Calculate grade
- Validate invalid marks
- Display grade result
- Custom background image

## Run

Install Streamlit:

pip install streamlit

Run the application:

streamlit run StudentGradeSystem.py
